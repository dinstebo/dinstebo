Hei, jeg heter Daniel. Jeg er statsviter, jobber som seniorrådgiver i Statistisk sentralbyrå (SSB) og bor utenfor Bergen.

### Hva jeg jobber med

I SSB har jeg ansvaret for den offisielle statistikken om videregående opplæring. Dataene kommer fra fylkeskommunene, NAV, Nasjonal vitnemålsdatabase og flere andre kilder, og mye av jobben handler om å få dem til å henge sammen: definisjoner, kodeverk, kontroller og behandlingsregler. Noe hentes som filer, noe gjennom API-integrasjoner mot blant andre Utdanningsdirektoratet.

De første årene skrev jeg mest SQL i SAS. Siden har jeg ledet arbeidet med å bygge produksjonen om til Python på SSBs plattform i Google Cloud, med versjonskontroll, tester og automatiske kvalitetskontroller. Jeg leder også et støtteteam for kolleger som går over til Python og R.

Til daglig: Python, SQL, Git, pytest og Google Cloud.
